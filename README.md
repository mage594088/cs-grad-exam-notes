# 資工考研筆記分享

嗨,我是 Mage (mage594088)。這份筆記是我 2019 年為了準備資工研究所考試,在考前那段
時間整理出來的讀書筆記,應該是全網唯一的電子化、非手抄版本,現在全部免費公開。無論
你是正在準備考試,還是單純需要相關資料複習、參考,都歡迎自由取用,希望能對你有幫助
。

這個 repo 的目標很單純:讓任何需要這份筆記的人,都能免費、方便地直接取得完整內容,
不希望被少數人拿去做成商品販售賺錢。

## 為什麼放在這裡

這份筆記原本只是考前準備時自己整理的讀書資料,後來陸續有學弟妹在 PTT 上看到分享文
章前來索取,我便做了一個線上表單方便大家申請。幾年下來,雲端硬碟裡累積了好幾個版本
的資料夾,最近有時間處理,決定搬到 GitHub 上,以後就以這個版本為主。

如果你是透過以前的 PTT 文章或
[申請表單](https://docs.google.com/forms/d/e/1FAIpQLScEugbmC-NmVyd_szysEz2xgAw7glwCyNXZrC7i2gBkl8yyrg/viewform)
找過來的:離散數學、資料結構、演算法、計算機組織、作業系統這五科筆記,現在都已經整
理到這個 GitHub repo 免費開放,直接下載即可。表單還是希望你幫忙填一下,單純留個記
錄,也讓你順便寫下目標校系,當作期許。

筆記難免會有錯或過時的資訊,如果發現的話歡迎開 Issue 或直接送出 PR 協助勘誤,詳細
方式請參考 [CONTRIBUTING.md](CONTRIBUTING.md)。目前家裡有兩個年幼的孩子,時間確實
比較有限,沒辦法保證能積極維護或更新,但只要你留言指出問題,或直接開 PR 幫忙修正,對
我來說都是很實質的幫助,看到都會處理,謝謝你的體諒。

如果想分享給其他人,麻煩直接分享這個 repo 的連結,不需要另外重新上傳一份 —— 這樣才
能確保大家看到的都是同一份、持續勘誤過的版本,這也是把這件事搬來 GitHub 的主要原
因。
